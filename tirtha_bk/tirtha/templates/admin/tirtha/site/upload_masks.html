{{ masked_count }} of {{ image_count }} image{{ image_count|pluralize }} at this site currently {{ masked_count|pluralize:"has,have" }} a mask.

A mask is a stencil in one image's pixel coordinates: white (or opaque) where the monument is, black (or transparent) everywhere else. It must be a PNG with exactly the same width and height as the image it belongs to. A mask drawn on a resized copy is refused, because the projection has no way to tell and would read the monument as background.

How a mask finds its image

Each file is paired with an image by its name. Any one of these works:

IMG_0117.png
masks the image uploaded as IMG_0117.jpeg (stem against stem).
IMG_0117.jpeg.png
masks it too. This is COLMAP's own convention, and the one the pipeline writes.
<image ID>.png
masks exactly that image, by the UUID shown on its admin page. Use this when two contributors uploaded photographs with the same filename: a name that matches more than one image is refused, never guessed, because the alternative is silently attaching a mask to a stranger's photograph.

Every image at this site is a candidate, whoever contributed it. One bad file does not discard the rest: each rejection is reported by name after the upload.
